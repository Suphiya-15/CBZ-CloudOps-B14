                                      Data Structure

Data Structure types:
1. List
2. Tuple
3. Sets
4. Dictionary

1. List : []
--> List is a collection of items that are ordered and chaneable (mutable)
--> Key Characteristics:
1. Ordered: The items in a list have a defined order, and this order will not chnage 
            unless you exlicitly modify it.
2. Mutable: you can change, add and remove items after the list has been created.
3. Allow Duplications: List can contain multipleitems with the same value.
eg:

my_list = [1,2,3,"seema","Amit",3]

Devops engg:
1. Server names
2. Service names
3. File names
4. Environments

2. Tuple: ()
--> A tuple is similar to a list, but with one key difference : tuples are immutable
--> meaning once a tuple is created, you can not change, add, or remove items from it.
--> Key Charactristics:
1. Ordered
2. immutable
3. Allows Duplications
eg:
my_tuple = (1,2,3,"Seema","Amit",3)

Devops engg:
1. IP address
2. Ports
3. Database enpoints
4. fixed cordinates
5. Version Information


3. Dictionary: {}
--> dictionary is a collection of key-value pairs. each key is unique, and it is used to access 
   the corresponding value.
--> key charactristics:
1. Ordered
2. Mutable
3. Unique keys
eg:
my_dictionary = {"name":"Seema", "Age": 25, "City":"Mumbai"}

Devops engg:
1. server Information
2. ec2 Information
3. docker container information 
4. user information
5. monitoring information


4. set: {}
--> A set is a collcetion of unique items. sets are unordered
--> key charactristics:
1. unordered
2. Mutable
3. No duplicates
eg:
my_set = {1,2,3,"seema","Amit",3}

devops engg:
1. ip address
2. kubernetes namespace
3. package names
4. error types
